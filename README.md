Deploy notes: see [DEPLOY.md](./DEPLOY.md).

## Host

Upload the entire `tikka-bar` folder to any static host.

```
tikka-bar/
├── index.html      # landing — specialties + View All
├── menu.html       # full menu
├── css/styles.css
├── js/config.js
├── js/main.js
├── images/
├── robots.txt
└── README.md
```
